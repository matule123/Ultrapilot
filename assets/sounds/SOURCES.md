# Notification sounds

The five WAV cues are original UltraPilot sounds generated by
`tools/build_notification_sounds.py`. They are short, quiet musical phrases with
soft starts and finishes. No ETS2LA audio or source code is included.

| Cue | Purpose |
| --- | --- |
| `boot.wav` | Application started |
| `engage.wav` | Autopilot engaged |
| `disengage.wav` | Autopilot manually disengaged |
| `warning.wav` | Activation rejected or new warning |
| `auto_off.wav` | Autopilot automatically disengaged |
